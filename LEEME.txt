REGISTRO DE VENTAS V5 - versión corregida

Esta versión conserva la aplicación de Registro de Ventas y corrige:
- distribución más espaciosa de la pantalla de venta;
- buscador y campo de valor recibido más compactos;
- formato de dinero sin mover las cifras ni el cursor al escribir o pegar;
- eliminación fiable del elemento seleccionado de la venta actual.

La aplicación NO usa inventario ni controla existencias.
Los datos del usuario se guardan en la carpeta datos/ junto al ejecutable cuando se ejecuta como EXE.

Para crear el EXE con GitHub Actions:
1. Sube el contenido de esta carpeta al repositorio.
2. Verifica que .github/workflows/crear-exe.yml exista.
3. Ve a Actions y ejecuta "Crear EXE de Windows".
4. Descarga el Artifact "RegistroVentas-Windows".
